# 제출 증빙 자료 체크리스트

배포 URL에서 아래 화면을 캡처해 이 폴더에 저장합니다. 캡처와 함께 실제 API 키나 개인정보가 보이지 않는지 확인합니다.

## 필수 스크린샷

1. `01-desktop-home.png` — 데스크톱 홈 화면과 상단 메뉴
2. `02-desktop-result.png` — `당근 1개, 달걀 2개 / 1인` 등의 정상 입력 후 AI 레시피 2개가 표시된 장면
3. `03-mobile-result.png` — 모바일 폭(예: 390px)에서 추천 결과가 한 열로 표시된 장면
4. `04-saved-dark.png` — 다크 모드에서 저장 레시피의 상세 보기와 삭제 버튼이 보이는 장면
5. `05-error.png` — 빈 필수 입력 또는 시간 초과·API 오류 안내 장면

## AI 코딩 도구 사용 증빙

이 프로젝트를 만드는 동안의 대화에서 다음 내용을 포함하는 화면을 캡처합니다.

- 서비스 아이디어와 타겟 사용자 결정
- AI 레시피 입력·출력·알레르기 처리 기준 논의
- 구현 요청과 코드 생성·검증 과정

## 제출 직전 테스트

- [ ] 빈 재료 또는 인원수: 필수 입력 안내 표시
- [ ] 정상 입력: 레시피 정확히 2개 표시, 모든 핵심 재료 사용량 표시
- [ ] 제한 충돌: 레시피 없이 수정 안내 표시
- [ ] 저장·상세 보기·삭제 및 새로고침 후 저장 목록 유지
- [ ] 다크 모드 전환 및 새로고침 후 테마 유지
- [ ] 데스크톱과 모바일에서 메뉴·카드·입력 폼 확인
- [ ] 배포 URL에서 `/api/recommend` 정상 호출 확인
