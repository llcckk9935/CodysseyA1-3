# AI 기능 테스트 케이스

| 구분 | 입력 | 기대 결과 |
| --- | --- | --- |
| 정상 | 당근 1개, 달걀 2개 / 1인 / 한식 | 핵심 재료를 모두 포함한 레시피 2개, 추가 재료는 각 2개 이하 |
| 수량 없음 | 당근, 달걀 / 1인 | 추천 가능, 사용량은 1인분 기준으로 제안 |
| 빈 입력 | 재료 또는 인원수 비움 | 필수값 안내, API 요청 없음 |
| 제한 충돌 | 달걀 2개 / 달걀 알레르기 | 레시피 없이 충돌 이유와 수정 방법 안내 |
| 식단 제한 | 두부 / 비건 / 1인 | 동물성 재료를 피하려 시도한 레시피와 확인 경고 |
| 모호 입력 | `맛있는 거` / 1인 | 식재료명 재입력 안내 |
| 장시간 응답 | 네트워크 지연 | 8초 후 추가 진행 안내와 입력 유지 |
