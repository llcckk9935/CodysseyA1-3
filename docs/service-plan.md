# 서비스 기획서 — 나를 요리해줘

## 1. 서비스 개요

- **목적**: 냉장고에 남은 특정 재료를 빠르게 활용하고 싶은 요리 초보자에게, 부담 없는 한 끼 레시피를 제안한다.
- **타겟 사용자**: 자취생, 요리가 익숙하지 않은 직장인, 남은 재료 처리에 어려움을 느끼는 사람.
- **핵심 가치**: “당근만 남았는데 무엇을 해 먹지?”라는 순간에 재료를 버리지 않고 바로 만들 수 있는 선택지를 제공한다.

## 2. 페이지·섹션 구성

1. **홈**: 서비스 소개, 입력 예시, AI 결과 미리보기, 추천 화면 진입 CTA
2. **레시피 추천**: 핵심 재료·인원수 필수 입력과 선택 제한 정보를 받아 AI 추천 2개를 표시
3. **나의 레시피**: 개별 저장한 전체 레시피를 접기/펼치기로 확인하고 삭제
4. **이용 안내**: 추천 기준, 알레르기·위생 한계, 개인정보·저장 방식을 고지

상단 메뉴 앵커로 각 섹션을 이동한다.

## 3. AI 기능 설계

### 입력

- 필수: 꼭 쓰고 싶은 재료(자연어, 수량 선택), 인원수
- 선택: 요리 스타일, 메뉴 형태, 식단 제한, 알레르기 주의 재료
- 식단·알레르기는 선택 칩과 직접 입력 태그를 함께 쓴다. 비어 있으면 제한 없음으로 처리한다.

### 출력

한 요청에서 OpenAI 호환 Chat Completions API로 추천 레시피 **2개**를 JSON으로 받는다. 서버가 형식과 핵심 제한을 검증하며, 두 레시피 모두 AI가 인식한 모든 핵심 재료를 포함한다.

- 메뉴명·추천 이유, 예상 시간·난이도·필요 도구
- 핵심 재료별 사용량과 비교 가능한 경우 예상 잔량
- 추가 재료(각 레시피 최대 2개), 선택 고명, 최대 5단계 조리 순서
- 반영을 시도한 식단·알레르기 제한 및 안전 경고

### 기준과 실패 처리

- 기본 양념은 소금·후추·식용유에 한정하며, 제한과 충돌 가능성이 있으면 기본으로 가정하지 않는다.
- 소금·후추·식용유 외 모든 재료(밥·면·달걀·간장 포함)는 추가 재료에 포함한다.
- 핵심 재료가 비건/알레르기 제한과 충돌하면 레시피를 만들지 않고 수정 방법을 안내한다.
- 모호하거나 식재료가 아닌 입력은 추측하지 않고 재입력을 요청한다. 수량만 없거나 불명확한 경우에는 추천 가능하다.
- 8초 후 진행 안내를 표시하고, 25초 후 화면 대기를 종료해 재시도를 제공한다. 네트워크·API·타임아웃 오류를 구분한다.
- 서버 SDK는 자동 재시도를 하지 않고 20초에 요청을 종료해, 사용자 화면의 25초 대기 제한 안에서 오류를 안내한다. 레시피 2개가 중간에 잘리지 않도록 출력 상한은 2,400토큰으로 둔다.
- 취소 후 늦게 온 응답은 화면·저장 대상에서 폐기한다.

## 4. 안전·개인정보 기준

- 알레르기 판단은 성분표·가공식품·교차오염을 완전히 검증하지 못한다. 불확실하면 안전하다고 단정하지 않는다.
- 변질·유통기한·보관 상태는 판단하지 않으며, 생고기와 달걀은 충분한 가열을 안내한다.
- 입력한 재료·식단·알레르기 정보는 AI 추천 생성 목적으로만 API에 전송한다. 서버는 별도 저장하지 않는다.
- 교육장 전용 API 게이트웨이를 사용하는 경우, 서버 전용 `OPENAI_BASE_URL` 환경 변수로만 Base URL을 설정한다.
- 로그인 없이 저장한 레시피와 테마 설정은 해당 브라우저 LocalStorage에 저장되며, 기기 변경·브라우저 데이터 삭제 시 사라질 수 있다.

## 5. 보너스 과제 반영

- **데이터 저장**: 개별 레시피 전체를 LocalStorage에 저장하고, 상세 보기·삭제를 제공한다.
- **UX 고도화**: 사용자 선택이 우선하는 다크 모드를 제공하고, 테마 값을 별도로 저장한다.
